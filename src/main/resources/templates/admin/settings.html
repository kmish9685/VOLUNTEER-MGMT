How Settings Alter Code Logic
  • platform_name:
    Dynamically read via SettingService.getValue() in GlobalModelAttributes and rendered on every page's navbar and title.
  • allow_registrations:
    If set to false, UserService.registerUser() blocks new signups and register.html displays a "Registrations are closed" banner.
  • max_hours_per_log:
    Enforced in HourLogService.logHours(). Volunteers cannot log hours exceeding this threshold in a single entry.
  • auto_approve_opportunities:
    Evaluated in OpportunityService.createOpportunity(). If true, newly posted events bypass Admin review and are immediately APPROVED.
